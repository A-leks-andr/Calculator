# 🧮 Flet Python Calculator

Стильный кроссплатформенный калькулятор, написанный на Python с использованием фреймворка **Flet**. Проект спроектирован по модульному принципу (MVC) и адаптирован для десктопных операционных систем.

## ✨ Особенности
- **Интерфейс в стиле iOS**: Черная контрастная тема с аккуратными скругленными кнопками.
- **Полноценный расчет процентов**: Поддержка сложных вычислений, таких как `200 - 10% = 180` и `200 * 10% = 20`.
- **Ввод с клавиатуры**: Возможность выполнять все операции с помощью физических клавиш компьютера (включая `Enter`, `Escape` и `Backspace`).
- **Безопасность**: Защита от деления на ноль (`Error`) и защита ввода от двойных точек (например, `5.5.5`).
- **Модульная архитектура**: Разделение интерфейса (`calc.py`) и математической логики (`calculator_logic.py`).

## 🛠️ Автоматизация и инструменты
В проекте настроен `Makefile` для быстрой разработки и контроля качества:
- `make run` — запуск калькулятора в режиме горячей перезагрузки (hot-reload).
- `make check` — быстрая проверка и автоматическое исправление импортов линтером **Ruff**.
- `make format` — форматирование кода по мировым стандартам Python.
- `make clean` — очистка проекта от временного кэша.
- `make build` — сборка проекта в самостоятельный `.exe` файл.

## 🚀 Как запустить проект

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/A-leks-andr/Calculator.git
   cd Calculator
   ```
2. Установите зависимости через менеджер пакетов `uv`:
   ```bash
   uv sync
   ```
3. Запустите приложение:
   ```bash
   make run
   ```

## 📦 Создание собственного независимого приложения (.exe)

Вы можете использовать этот код как основу для сборки своего собственного
полноценного Windows-приложения, которое будет работать на любом компьютере
без необходимости устанавливать Python!

Для этого выполните следующие шаги:
1. Замените файл `calc.ico` в корне проекта на свою собственную квадратную
   иконку в формате `.ico`.
2. В файле `Makefile` в блоке `build` вы можете изменить название приложения
   в параметре `--name "Ваше Название"`.
3. Запустите команду сборки:
   ```bash
   make build
   ```
4. После окончания процесса загляните в созданную папку **`dist/`** — там 
   будет лежать готовый файл `Ваше Название.exe`. Вы можете переносить его на 
   флешку, отправлять друзьям или загружать в релизы!
